Bem-vindo(a) ao Portal

Este é um site estático e informativo, criado para reunir, em um só lugar, os principais conceitos estudados na disciplina de Banco de Dados. Não há conexão com um banco de dados real nem formulários funcionais — o objetivo é puramente didático: revisar teoria, visualizar diagramas e treinar a leitura de comandos SQL antes das aulas práticas com MySQL/XAMPP e SQL Server.

Sobre este Portal

Este site foi desenvolvido como projeto de estudos da disciplina de Banco de Dados, no curso Técnico em Desenvolvimento de Sistemas da Etec Professor Camargo Aranha.
