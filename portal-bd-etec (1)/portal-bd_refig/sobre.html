Sobre este Projeto

O Portal de Estudos de Banco de Dados é um projeto acadêmico desenvolvido para a disciplina de Banco de Dados do curso Técnico em Desenvolvimento de Sistemas, da Etec Professor Camargo Aranha (Mooca, São Paulo).

O site foi remasterizado a partir do template gratuito Dopetrope, da HTML5 UP, adaptado para fins puramente educacionais. É um site 100% estático: não existe backend, banco de dados real ou processamento de formulários — todo o conteúdo é fixo, escrito diretamente em HTML/CSS para servir como material de consulta e revisão.

Instituição
